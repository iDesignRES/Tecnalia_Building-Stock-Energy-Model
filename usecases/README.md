# iDesignRES: Building Stock Energy Model

## Use cases

This directory contains two types of CSV files for all regions supported by the model:

- Files resulting from the preprocessing of buildings (*XXXX_preprocess.csv*).

- Files containing the available roof area for PV installation (*XXXX_solar.csv*).

These files are used by the model as input data for the following supported countries and regions:
